Nmap Network Scanning and Service Enumeration

Project: Network Reconnaissance
Tool: Nmap
Category: Network Penetration Testing
Author: CyberLord

1. Project Overview

This project demonstrates practical use of Nmap, a network scanning tool used by cybersecurity professionals to discover hosts, identify open ports and examine running services.

Testing was performed in an authorised environment.

2. Objectives

- Understand network reconnaissance.
- Identify open, closed and filtered ports.
- Detect running services.
- Identify service versions.
- Interpret scan results.

3. Tools Used

- Kali Linux
- Nmap
- Linux Terminal

4. Commands Practised

Basic Network Scan

"nmap <target>"

Used to scan common TCP ports on a target.

Service Version Detection

"nmap -sV <target>"

Used to identify services and their versions.

Specific Port Scanning

"nmap -p 80,443 <target>"

Used to scan selected ports.

Operating System Detection

"nmap -O <target>"

Used to attempt operating system identification.

5. Skills Demonstrated

- Network reconnaissance
- Port scanning
- Service enumeration
- Version detection
- Basic scan-result interpretation
- Network security assessment

6. Learning Outcome

This project strengthened my understanding of network services, port states and the importance of identifying exposed services during a security assessment.

7. Conclusion

Nmap is an important tool in network penetration testing. Understanding its scanning options and interpreting its results helps security professionals identify potential areas requiring further investigation.
